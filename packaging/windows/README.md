# Microsoft Store artwork

The Store route, manifest template, Partner Center identity, and version
rules are documented in [Microsoft Store packaging and identity](../../docs/store-packaging.md).

Regenerate the checked-in PNGs from the original 1254×1254 Canvaz artwork in
`src/assets/icon.png`:

```sh
python3 -m pip install Pillow
python3 scripts/generate-store-images.py
```

The script works from any working directory. It preserves the existing logo,
lettering, proportions, and source background. The largest box-art export is
upscaled from the original artwork. Box and poster art center the icon on an
opaque dark background with padding; app tiles use the full square icon.

## Partner Center listing uploads

Upload the files in `store-listing/` to the corresponding Store listing image
fields. These are separate from the icons inside the application package.

| Artwork | Dimensions (pixels) |
| --- | --- |
| App tiles | 71×71, 150×150, 300×300 |
| Box art | 1080×1080, 2160×2160 |
| Poster art | 720×1080, 1440×2160 |

This set matches Pigtail's listing exports. Not every promotional image is
mandatory for a desktop app; use the fields offered by Partner Center.
Application screenshots are separate and are not generated by this script.
Every successful Store workflow run uploads `store-submission.zip` in the
`canvaz-store-submission-<run-id>` artifact. It contains these listing images,
all package icons, the unsigned MSIX and its metadata, and submission instructions.
Tagged GitHub releases attach the same ZIP. Prepare Windows Store edition
screenshots for the final listing; screenshots are separate from this archive.
See the [Microsoft Store image guidance](https://learn.microsoft.com/en-us/windows/apps/publish/publish-your-app/msix/screenshots-and-images).

## MSIX package icons

`msix/Assets/` contains the base icons and 200% display-scale variants:

| Asset | Base | 200% variant |
| --- | --- | --- |
| StoreLogo | 50×50 | 100×100 |
| Square44x44Logo | 44×44 | 88×88 |
| Square150x150Logo | 150×150 | 300×300 |

The `.scale-200.png` filenames identify the high-DPI variants. The MSIX manifest
template references the base filenames; `scripts/build-msix.py` indexes
the scaled assets with MakePri. These assets do not change the icons used by
the existing Tauri installers.
